# Beginner Projects in ReactJS
All projects were created for the free course on the [Archakov Blog](https://www.youtube.com/watch?v=eS0GL73tkmw) channel.

Each project is stored in a separate branch.

**👀 What will we learn?**

## Guest List (Users)
![1660249789449](https://user-images.githubusercontent.com/12086860/184236601-2c8d94bf-105c-4b48-982c-65a6ed4f8c51.png)

**🌿 Branch**: `users`

**👀 What will we learn?**
1. Working with the `useEffect` hook
2. Sending requests to the backend using `fetch` and rendering the data
3. Skeleton loading using the `react-content-loader` library
4. User search
5. Rendering a list of users
6. The spread operator
7. Adding/removing users from the invitations array
8. Displaying loading state information
